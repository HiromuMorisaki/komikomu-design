# アフィリエイト規約サマリ

> **最終更新**: 2026-05-30
> **次回見直し予定**: 2026-11 末（半年ごと）

本アプリのアフィリエイト運用は、各 ASP・各 EC モール・国内法令を厳守して設計する。本ドキュメントは、規約の最新サマリと、コードに反映すべき表示・データ取り扱いルールをまとめる。

**注意**：規約は随時更新されるため、本ドキュメントを **半年ごとに見直す** ことを運用ルールとする。詳細は [見直し運用](#8-見直し運用) 参照。

## 1. 利用予定プログラム一覧

| EC | アフィリエイト経路 | 主要要件 | 報酬発生条件 |
|---|---|---|---|
| Amazon.co.jp | Amazon アソシエイト・プログラム | 紹介リンク経由のクリック → 24 時間以内の購入、180 日以内に適格売上 3 件で承認継続 | クリック後 24h 以内の確定購入 |
| 楽天市場 | 楽天アフィリエイト（楽天ウェブサービス） | リンク経由クリック → 90 日以内の購入、承認制ハードル低 | クリック後 90 日以内の確定購入 |
| Yahoo!ショッピング | バリューコマース経由 | 提携審査あり、サイト/アプリ事前審査必須 | バリューコマース基準による |

## 2. リンク生成ルール

### 必須事項

- **すべての商品リンクは ASP のアフィリエイト ID を必ず付与した URL で生成する**
- **アフィリエイト ID・トラッキングタグはサーバ側（Supabase Edge Function の環境変数）で一元管理**し、クライアント（iOS / Web / 拡張機能）には露出させない
- リンク生成エンドポイントは `affiliate-link` Edge Function に集約
- iOS / Web / 拡張機能のどこから開いても同じ規約準拠リンクが生成される

詳細は [ADR 0003: server-side-affiliate](decisions/0003-server-side-affiliate.md) 参照。

### 推奨事項

- アプリ内ブラウザではなく **外部 Safari**（`UIApplication.shared.open`）でリンクを開く
  - 理由：`SFSafariViewController` は ASP Cookie 共有が一部効かないケースあり、CV を取り損なう
  - 規約面ではなく実利上の選択

## 3. 必須開示文言

### Amazon アソシエイト・プログラム

**必須掲載文言**：

> Amazon.co.jp アソシエイトとして、当アプリは適格販売により収入を得ています。

**掲載場所**：

- アプリ起動後、アクセスしやすい場所（推奨：設定 > このアプリについて）
- アプリストアの説明欄
- App 内の比較結果画面の冒頭バナー

### 楽天アフィリエイト

特定の固定文言はないが、以下の表示を実装：

> 楽天市場の商品情報は楽天ウェブサービス（楽天アフィリエイト）経由で取得しています。価格・在庫情報は取得時点のもので、最新の情報は各商品ページをご確認ください。

**掲載場所**：価格カード単位 + 設定 > このアプリについて

### 景品表示法・ステマ規制（2023 年 10 月施行）対応

**規制概要**：事業者の表示であることが消費者に明瞭でない場合、不当表示として規制対象。

**コミコムの対応**：

- 各商品カードに **「PR」または「広告」バッジ** を視認可能なサイズで表示
- 比較結果画面の最上部に **固定の開示バナー** を配置
- 設定 > このアプリについて に明文掲載

**バナー文言例（共通使用）**：

> 本アプリは Amazon アソシエイト・楽天アフィリエイト・バリューコマース等のアフィリエイトプログラムにより収益を得ています。比較結果の表示順は実質価格（送料・ポイント還元込み）で算出しており、報酬率による並べ替えは行いません。

## 4. 価格・商品情報の鮮度表示

各 ASP が「価格表示の最新性を担保すること」を規約で求めている。

| 表示要素 | 実装内容 |
|---|---|
| 取得時刻 | 各商品カードに「取得：YYYY/MM/DD HH:mm」を表示 |
| 最新価格リンク | 「最新価格は各サイトで確認」リンクを商品カードに必ず併記 |
| 情報の鮮度警告 | 取得から 24h を超えたデータは「最新ではない可能性」の注記を表示 |

## 5. データ取得・保存ポリシー

### 取得

- **スクレイピング禁止**。必ず公式 API を使用する（[ADR 0002: no-scraping](decisions/0002-no-scraping.md)）
- API のレート制限を遵守（楽天 API は通常 1 秒 1 リクエスト、サーバ側で制御）

### キャッシュ

- 取得した生レスポンスは `price_cache` テーブルに **TTL（24h 以内）付き** で保存
- `expires_at` カラム必須、cron で物理削除
- 詳細は [ADR 0004: price-cache-ttl](decisions/0004-price-cache-ttl.md)

### 永続保存

- **価格の生データは恒久保存しない**
- 価格履歴グラフ用には **日次の集計値（min/max/avg）のみ** を `price_history_daily` テーブルに永続保存
- これにより API 規約の「価格情報の取り扱い」要件を満たす

## 6. 比較ロジックの中立性

**禁止事項**：

- アフィリエイト報酬率の高い順に並べる
- 特定 EC を意図的に優遇する

**実装方針**：

- 並び順のロジックは **「実質価格（税込 − ポイント還元相当 + 送料）の昇順」** を原則とする
- ロジックは `ios/Core/Utilities/PriceCalculator.swift` に集約し、テストで担保
- UI に「並び順：実質価格の安い順」を明示

**根拠**：景表法の優良誤認回避 + 長期的なユーザー信頼

## 7. 設計実装ガイドライン

### コード境界

| モジュール | 役割 |
|---|---|
| `ios/Core/Affiliate/` | 開示バナー・PR バッジ・必須文言の **表示** |
| `backend/supabase/functions/_shared/affiliate.ts` | アフィリエイト **リンク生成の正本** |
| `backend/supabase/functions/affiliate-link/` | iOS / Web / 拡張機能から呼ばれる API エンドポイント |

### 必須テスト

`backend/tests/affiliate.test.ts` で以下を検証：

- 楽天/Amazon/Yahoo それぞれのアフィリエイト ID が **URL に正しく埋め込まれている**
- 環境変数未設定時にリンク生成が **エラーになる**（フォールバック禁止）
- 生成 URL が **HTTPS** であること
- 同一商品で同一 EC を指定した時、複数呼び出しで **同じ URL が返る**（パラメータ順の安定性）

## 8. 見直し運用

- **頻度**：6 ヶ月ごと（毎年 5 月末・11 月末）
- **担当**：開発者本人
- **手順**：
  1. 各 ASP の利用規約ページを最新版で確認
  2. 変更があれば本ドキュメント該当セクションを更新
  3. 必要に応じて開示文言・コード（`_shared/affiliate.ts` 等）を修正
  4. PR を作成し、変更履歴を残す
- **自動化案**：半年ごとに GitHub Issue を自動起票するワークフローを Phase 2 で導入
